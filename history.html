MeaningSpace と DPマルチエージェント基盤の各機構について、設計・実装・実証の確定日を記録します。個人開発（開発者1名 + AI）による先行実装のデジタルアンカーです。

Era 1 — AIとの対話、業務自動化からの出発
2023-02

AIとの対話を始める（ChatGPT）

最初の会話は 2023-02-07。この時期の ChatGPT との会話 1,567 件も、のちに MeaningSpace に取り込み、いまも引ける形で残っている。

2024-09

Claudeによる業務自動化を開始

RPA・BI・帳票処理などの実務自動化。以後すべての基盤となる「AIとの共同作業」の運用知見を蓄積。

2025-03

MeaningSpace構想 — 方向の反転

「AIを人間のファイル構造に合わせる」のをやめ、「人間がAIの意味空間に入る」設計へ転換。減算設計（ノイズを引けば意味が結晶する）を基本哲学として個人AI記憶OSの開発を開始。

Era 2 — 意味記憶OSの確立
2026-01-02

現行DuckDB結晶データベース稼働（第1結晶）

会話を「結晶」として保存する現行スキーマの初日。以後2026-07-16までに1,983結晶へ成長。

2026-05-16

マルチエージェント企業OS構想を文書化

MeaningSpaceを基盤に複数AIエージェントを組織として運用する構想を結晶化。

2026-06-04 〜 06-07

QIS（Quantum Inspired Semantic Space）設計〜Phase 0+1実装

成功・失敗ベクトル（posi_vec/nega_vec）を全結晶にバックフィルし、干渉スコアリングの土台を実装。

2026-06-05 〜 06-07

SubtractLabブランド確立・subtractlab.com公開

GitHub Pages公開（06-07 deploy）、Search Console登録、sitemap送信。

2026-06-11

QIS干渉式 Model 2 確定

proximity主軸＋成功超過ボーナス／失敗超過ペナルティの合成式を実データで実証。

2026-06-13

結晶化の完全機械化 — 手動Raw方式を撤去

画面コピペ由来の生データ経路を封鎖し、会話ログ（conv_jsonl）起点の機械パイプラインへ一本化。

Era 3 — 司令塔と自己進化
2026-07-04

サブエージェント作法v2 — Chain / Swarm / Loopの3形態を体系化

直列・並列・検証周回の使い分けと昇格ラダー（軽量モデル→上位モデル）を運用規約化。

2026-07-05 〜

Clara bridge — AI同士のファイルキュー対話ブリッジ設計

別AI（Clara）との双方向ブリッジをファイルキュー＋CDP監視で設計・部分実装。

2026-07-08

自己学習パイプライン実装（SelfEval → EWMA → self_preferences）

毎会話の自己評価を減衰累積し、行動規範として次セッションのboot時に自動装着。同日、SelfRepair（弱みスコア≤−3.0で改修Taskを自動起票）を設計。司令塔の構造欠陥4点修正とLoop体系化も同日完了。

2026-07-11

self_preferences v8 稼働・コスト構造の実測解剖

API課金経路とWeb枠経路の費用構造を実測比較し、DPルート優先の方針を確定。

Era 4 — DPマルチエージェント（Web Claudeを束ねる）
2026-07-13

DPマルチエージェント基盤確定 — 5レーンCDP構成

1レーン=1Chrome=1プロファイル=1CDPポートの分離設計。実測で確定した知見: 同時実行上限（アカウント全体）、時差投入2.5秒、ゾンビ応答と協調停止の順序（3本生成中→3.6秒で全停止）、利用者設定の人格汚染と中和ヘッダによる遮断、ファイル操作の「触る係=Python/決める係=DP」分離、削除権限の不付与。同日、AutoCrystallize DPルート全8ステップを実証。

2026-07-14

恒久化 — dp_lease / dp_journal / dp_swarm / COMMANDER_PLAYBOOK

プロセス跨ぎのグローバルスロット排他（札ファイル・stale回収15分）、構造化ランジャーナル、UI文字列判定の全廃（DOM構造属性へ移行）、Haiku量産プリセット（決定的検証→同モデル再試行→上位モデル昇格）、司令塔判断表。dp_swarm.pyベンチ4/4 PASS・9〜15秒/件・追加費用¥0。

2026-07-15

能動的コーディングループの実戦投入

司令塔がchecksで検証を回しながらDP対話レーン（dp_chat）に改修を再依頼するEvaluator-Optimizerループで、F6動線フックv2（記憶未参照の機械検知）をDPが実装。dp_swarm完成・応答洗浄の恒久化。システム取扱説明書自体もDPが生成。

2026-07-16

本タイムライン・アーキテクチャ全貌を公開

DPマルチエージェント／自己学習／自己修復／能動的コーディングの全構造を Architecture で図解公開。

Era 5 — 意味の住所と、公開記録
2026-09-01

SweepSearch を退役 — 検索を一本化

言葉の検索（BM25）と意味の検索（ベクトル）を順位で合わせる検索に一本化。結果からは節へ降りて読む形にした。

2026-09

結晶の節ごとに、元の行への住所

会話の結晶の各節に、元の会話ログの行への住所を付けた。住所はモデルに思い出させず、決まった候補の中から選ばせる。

2026-09-21

作法を「灯らせて」引く道具

作法（手順）を、問いとの近さが閾値0.80を超えた時だけ、題名と読み方だけで返す道具を新設。検索結果への同梱はやめた。

2026-10-04

プログレスマップ — ファイルの地図と、理由付きの変更台帳

ファイルとコードの「今」を地図にし、変更ごとに札・理由・逆向きの差分を台帳に積む。札は会話の記録に残り、見る時に会話の節へ結ぶ。git は使わない。

2026-10-07

設計をリポジトリとして公開（1〜2本目）

meaningspace と ai-native-groupware を、日付の入った設計の公開記録として公開。

2026-10-24

作法の一覧をプロンプトから外す

いつも読み込むプロフィールにあった25行の作法の一覧を外した。外す前に、25枚すべてが自分の仕事の問いで3位以内に灯ることを確かめた。

2026-11-07

設計の公開（3〜4本目）とトップページの作り直し

progress-map と threshold-skills を公開。subtractlab.com のトップを、文字で読める HTML に作り直した。
