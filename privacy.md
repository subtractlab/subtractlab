# Privacy Policy

Last updated: November 25, 2026

This policy covers the website subtractlab.com and **SubtractLab SNS Collector**, a private tool of SubtractLab.

## Who uses SubtractLab SNS Collector

SubtractLab SNS Collector is used only by Koji Okuda, the operator of SubtractLab, with SubtractLab's own Google account. It is not offered to the public, and no other person can sign in to it.

## What it reads

With the owner's consent, the tool reads, and only reads:

- YouTube channel and video statistics of the SubtractLab channel (YouTube Data API, YouTube Analytics API)
- Search performance and indexing status of subtractlab.com (Search Console API)
- Visitor counts of subtractlab.com (Google Analytics Data API)
- The sender, subject, date and a short preview of recent messages in the SubtractLab Gmail mailbox (Gmail API, read-only)

It never sends, deletes, labels or changes any message, and never changes any setting of any account.

## How the data is used

The data is used only to give the owner a private daily summary of SubtractLab's channel numbers and of mail that needs his attention. It is kept privately by the owner. It is not sold, not shared with anyone, not used for advertising, and not used to train AI models.

SubtractLab SNS Collector's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

The owner can remove the tool's access at any time from [Google Account permissions](https://myaccount.google.com/permissions). Stored summaries can be deleted on request.

## The website

subtractlab.com uses Google Analytics to count visits. Analytics collects standard, anonymous usage data through cookies. You can opt out with the [Google Analytics opt-out add-on](https://tools.google.com/dlpage/gaoptout).
